# The Fittest · 品牌图标

## 设计：三向非传递循环

**一个图形同时说清三件事。**

```
博弈   三方相互压制，谁都不能通吃
演化   形态沿环轮转，形不变而位在变
适应   这一代领先的，下一代被压制
```

图形由**三段楔形**组成一个完整圆环，每段顺时针由细变粗，粗端指向下一段。

- **非传递循环**：A 打 B、B 打 C、C 打 A，是博弈论里"没有优势策略"最经典的模型。
  它同时也是"没有唯一正确答案"这句话的图示，不需要任何文字补充。
- **为什么是环而不是箭头向上**：项目的内核是「适应 ≠ 最强」。
  向上的箭头会被读成「赢者通吃」，而环形天然否定终点——没有山顶，只有轮转的位置。
- **为什么是渐宽的楔形而不是三角箭头**：外凸的箭头在 48px 下会走样成毛刺，
  外轮廓也不再是圆。楔形把方向感放在**宽度变化**里，任何尺寸下轮廓都是干净的圆。

## 规格

| 项 | 值 |
| :--- | :--- |
| 画布 | 1024 × 1024，圆角比例 0.2237（贴近 iOS squircle） |
| 环半径 | 画布宽度的 0.262 |
| 带宽 | 尾部 0.040 → 头部 0.070（画布宽度比例） |
| 每段扫过 | 96°，段间空隙 24° |
| 前倾 | 内缘相对外缘前倾 18°（统一前倾 = 转向感） |
| 底板 | 竖向渐变 `#FFFFFF → #EDF1F6` |

### 配色

| 用途 | 色值 |
| :--- | :--- |
| 黄橙（博弈） | `#E4572E` |
| 蓝（演化） | `#2E7DE4` |
| 绿（适应） | `#21A179` |

三色**明度接近**，因此在灰度打印或极小尺寸下强度一致，不会有一色"跳出来"。
三色在 48px 下仍可区分；深色背景下同样可用。

## 重新生成

```bash
.venv\Scripts\python.exe docs\brand\build_icon.py
```

改 `RADIUS_F`（环大小）、`RIBBON_TAIL` / `RIBBON_HEAD`（楔形粗细变化）、
`SPAN_DEG`（段长）、`SHEAR_DEG`（前倾）、`COLORS`（配色）即可。
`build_icon.py` 里 SVG 与 PNG 共用同一组采样点，所以两者永远是同一个形状。

## 小尺寸验收

已逐尺寸核对：**48×48 下三段颜色仍可区分、环的轮廓完整、无毛刺**。
这是把三角箭头换成楔形的原因——先前的箭头实现在 48px 会糊成锯齿。
