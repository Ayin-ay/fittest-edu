# Trust Evolution 策略参数搜索报告

**引擎版本** 1.2.0　**日期** 2026-10-02
**目标**：在系统的真实选择压力下，找出**稳定胜率最高**的策略
**结论提要**：本项目在搜索过程中连续修正了四次结论。跨层全搜索（第九节）确认
**末轮背叛（`BS{N}`）配合报复触发器是最强组合**：`BS3+R1-1` 平均份额第一（0.3443），
但最差 seed 会被清零；若求稳定，`BS2+R1-1` 是唯一 100% 存活的批次冠军。
我前几轮给出的"冠军"全部作废，原因是候选池存在系统性盲区，详见第七、九节。

## 一、方法

### 1.1 为什么不直接用两两对局

收益矩阵是经典 Axelrod `(T,R,P,S) = (5,3,0,1)`，**非零和**：
合作-合作合计 6，背叛-背叛合计仅 2。

用固定对手池打原始得分会奖励"专门剥削合作者"的策略。实测
`SM`（永远背叛）拿到 **19 胜 0 负**，因为 `R1-1` 只报复 1 轮就原谅，
被它每轮单方面攫取 5 分。这是**指标伪影**，不是真实能力。

改用演化选择压后，参照策略的画像立刻合理：
`SM` 夺冠率 64% 但存活率仅 34%（早期称霸、后期被清剿），
`S0` 夺冠 10% / 存活 24%（被持续挤压）。

### 1.2 指标

全部读自 `evolution_archive.build_analysis()`——与面板、与 AI skill
消费的是**同一份分析视图**。

| 指标 | 含义 |
| :--- | :--- |
| `mean_share` | 后半程平均种群份额（相对量） |
| `survival` | 结束仍存活的 seed 比例 |
| `dominance` | 曾登顶的 seed 比例 |
| `worst_share` | 最差单个 seed（稳定性项） |
| **生态适应度** | `generation_summary.average_fitness` 后半程均值（**绝对量**） |

**为什么必须加最后一项**：份额是相对量、适应度是绝对量。
实测证明只看份额会失明——当末轮背叛基因 100% 覆盖时，
份额分布完全不变，而生态适应度从 2.996 掉到 2.897（-3.3%）。
只按份额排名，对"个体理性、集体灾难"的漂移毫无反应。

### 1.3 打破初始对称

第一轮设计有致命缺陷：每策略统一 10 席，而 `EXTINCTION_SIZE=3`（≤3 席淘汰）
与 `MUTATION_MIN_SIZE=10`（需 >10 席才能变异）——**10 席恰好两边都不触发**，
既不淘汰也无法创新，退化为纯分配博弈。

修正：规模阶梯 `[4,6,8,10,12,14,20]` + 填充 2×13 = 100，
并**按 seed 轮换**分配（平衡设计）。区分度从"冠亚军差 0.011"提升到"0.079"。

### 1.4 内置质检闸门

工具自带检查：存活率全 100% 或冠亚军差距 <0.01 时直接报警，拒绝输出无意义排名。

## 二、过程中发现并修复的引擎缺陷

### 2.1 席位泄漏（1.0.0 → 1.1.0）

扩大到 322 候选后崩溃：G111 席位 **104 > 容量 100**。

根因是上轮修复漏了两处：`promote_subspecies()` 不检查编码是否被占用；
**`allocate()` 与 `reproduce()` 的配额表以 `encoding` 为键**，
重复编码被合并成一个键后，两个对象拿到**同一份配额**。

已改为**按位置索引分配**，结构性免疫。7 组回归全过，含主动注入重复编码的对抗测试。

### 2.2 停滞破冰器失效（1.1.0 → 1.2.0）

追踪发现 16 策略的密集生态里 **300 代零事件**，破冰器从未触发。

归因实验（不能靠猜）：

| 配置 | 亚种生成 | 最长冻结 |
| :--- | ---: | ---: |
| 1.0.0 原样 | 0 | 300 代 |
| 只改判据（换手席位） | **0** | **300 代** |
| **只改门槛（>10 席 → ≥2 席）** | **15** | **19 代** |
| 1.2.0 现在 | 15 | 19 代 |

**决定性的是候选门槛**：破冰器原本要求 `population_size > MUTATION_MIN_SIZE`，
而冻结的密集生态里十几条策略分 100 席，**谁都不到 10 席**，破冰器结构上无法行动。

判据那半仍被保留：改为"换手席位总数"后与物种数无关，且不再把
"多物种各换 1 席"误判为冻结。

### 2.3 网页端与脚本一致性（已验证）

用 `AppTest` 真实驱动网页端点 60 次「下一轮」，与无头 `run(60)` 比对
`generation / rng_state / history / fitness_history / events / final_species /
generation_records`——**全部逐位一致，包括 RNG 内部状态**。

## 三、行为等价：一个被忽视的巨大冗余

不同编码可能是同一个策略。`M{N}` 收窄记忆窗口，而当触发器只看对手最近 1 轮时，
窗口大小不影响任何读数。

用 `tools/equivalence.py`（29 个探针 × 3 seed，比对**完整动作向量**）
对全部 322 个候选分组：

**322 个编码 → 只有 160 种不同行为，162 个是别名（50%）。**
最大等价类 **54 个**：

```
B1-2 == B1-2+M2 == B1-3 == B1-M+M2 == H2-1 == K1-2 == K2-2
== RC1-1 == RC1-M == S0+M2 == ...        （共 54 个）
```

已把这一推理能力写入 skill（`二·五、行为等价推理`），要求分析前必须先归并。

**注意反面教训**：`R1-M+M2` 看着像 `R1-2`，实测**不等价**——
`R1-M` 触发后永久背叛（`CDDDDDDDDDDDD`），`R1-2` 只报复 2 轮（`CDDCCCCCCCCC`）。
**必须实测，不能靠读编码猜。**

## 四、分层决赛：发现选择偏差闭环

原决赛 7 个策略 **100% 共享 `R` 触发器**，默认槽只用 `S`/`D`，
模块数 ≥3 的只有 1 个（14%）。而引擎随机生成：**95% 是多模块策略**，
六种触发器均匀分布。

| 维度 | 原决赛 | 随机生成 | 覆盖度 |
| :--- | --- | --- | ---: |
| 默认槽 | `S`,`D` | 7 类 | 29% |
| 触发槽 | 仅 `R` | 6 类 | 17% |
| 模块数≥3 | 14% | 95% | — |

**这是一条自我实现的结论链**：我主要搜 R 家族 → R 家族夺冠 →
我只让 R 家族进决赛 → 宣布"R 家族最优"。

### 4.1 重做：四组分层阵容

30 seed × 250 代 × 2 套阶梯 = 240 次演化。

| 组 | 成员 | 生态适应度 | Shannon |
| :--- | :--- | ---: | ---: |
| **A 触发家族分层** | `R1-1` `P1-1` `B1-3` `K1-2` `H2-1` `RC1-1` `F1-1+RC1-1` | 2.5822 | 1.584 |
| **B 默认槽分层** | `S1` `F2-3` `T1-2` `D0` `AD1` `W` `BS3` | 2.4947 | 1.552 |
| **C 纯随机基线** | 7 个 `random_strategy` 生成的编码 | 2.5174 | 1.284 |
| **D 搜索冠军** | 前轮 7 名（全是 R 家族） | **2.9004** | **2.688** |

**三个发现：**

1. **多样性本身就是优势。** D 组（同族扎堆）适应度 2.90、Shannon 2.69；
   A/B/C（策略各异）只有 2.49–2.58、1.28–1.58。
   D 组的优势不来自"策略更强"，而来自**行为同质、互相不冲突**。

2. **手工构造完胜随机生成。** C 组 7 个随机多模块策略份额全部 ≤0.0045、存活 0–7%；
   D 组 `R1-1` 拿到 0.0752、`S0` 0.0815 且 100% 存活。**约 17 倍差距。**

3. **一旦对手范式多样，强弱立刻分明。** D 组里 `R1-1` 100% 存活；
   掉到 A 组后只剩 77%，而 `P1-1` 42%、`RC1-1`/`K1-2`/`H2-1`/`B1-3` **全部 0%**。
   **`R` 家族确实是当前最强行为范式。**

## 五、受控实验：末轮背叛的真实价值

上一轮我漏掉了 `BS{N}`（末轮背叛）**与触发器的跨层组合**。
单独对局测量显示 `BS1+R1-1` 确实更强（17 个对手中 13 个更好、0 个更差、
平均 +0.067 分/回合，对能骗到末轮合作的对手正好是理论上界 +0.100）。

**受控实验设计**：共同对手固定为 A 组的 6 个多样策略 + `S0` `SM`，
**只换第七个挑战者槽位**。40 seed × 250 代 × 2 阶梯 = 320 次演化。

| 挑战者 | 平均份额 | 存活率 | 夺冠率 | 生态适应度 |
| :--- | ---: | ---: | ---: | ---: |
| `R1-1`（基线） | 0.1442 | 71% | 41% | 2.6139 |
| `BS1+R1-1` | 0.3302 | 85% | 78% | 2.6464 |
| `BS2+R1-1` | 0.3226 | **89%** | 61% | 2.5533 |
| **`BS3+R1-1`** | **0.4498** | 85% | **84%** | 2.6305 |

| 变体 | 份额增益 | 存活率 | 夺冠率 | 生态适应度 |
| :--- | ---: | ---: | ---: | ---: |
| `BS1+R1-1` | **+129%** | +14% | +36% | +0.033 |
| `BS2+R1-1` | +124% | +17% | +20% | **-0.061** |
| `BS3+R1-1` | **+212%** | +14% | +43% | +0.017 |

**加一个末轮背叛模块，份额翻倍以上。** 增益远超两人对局的 +0.1，
因为它还有间接价值：对手看不到编码，末轮背叛让对手**无法报复**，
还可能诱使对手提前转入防御姿态而被他方乘虚而入。

**一个未解释的异常**：`BS2` 生态适应度反而低 0.061。可能存在生态稳定性的非单调
（背刺 2 轮恰落在不利中间态），也可能是 40 seed 的噪声。**此条尚未验证。**
（第九节提供了一条同向线索：跨层搜索里 `BS2+R1-1` 是唯一 100% 存活的批次冠军，
支持"`BS2` 以峰值换稳定"的猜测，但仍未直接测到适应度。）

## 六、轮次追踪：运行中实际发生了什么

### 运行 A（R1-1 家族 + 噪声）— 大扩张后彻底冻结
- G0–49：9→11 种，24 事件；`SM` **G9 灭绝**、`R1-1+C4-D` **G11 灭绝**
- G50–149：11→16 种，Shannon 2.44→2.74
- **G150–249 零事件**，整整 100 代僵持；终局极度分散（前 5 名各 7–9 席）

> 这直接暴露了 2.2 节的规则失效，1.2.0 已修。

### 运行 B（R1-1+RPT 宽容家族）— 双向周期振荡
- `SM` **G8 灭绝**
- **G178 起稳定振荡**：`R1-1+RPT1-1` → `R1-2` → `R1-1+RPT1-1` → …
  每隔 1–2 代交替夺冠，而前 178 代只更替过 2 次。典型的**循环克制**。

### 运行 C（R1-3 长报复家族）— 噪声模块被定向淘汰
- **G13** `R1-3+C4-D` 灭绝、**G14** `R1-3+C2` 灭绝、**G20** `SM` 灭绝
- 三个带概率随机翻转的变体**全部死亡**：噪声在报复型生态里是**自毁机制**
  （随机背叛触发对手报复，把自己拖进互殴）
- 幸存并夺冠的全是**纯确定性**变体

### 跨运行规律

| 规律 | 证据 |
| :--- | :--- |
| 纯背叛者早期称霸、后期崩盘 | `SM` 夺冠 64% / 存活 34% |
| 亚种是生态主要发动机 | 每运行 40–70 次生成，独立成功率约 1/3 |
| 宽容模块（`RPT`）是稳定器 | 振荡运行中长期共存的另一半 |
| **噪声模块（`C2`/`C4`）在报复生态中致命** | 三次独立运行中全部灭绝 |
| 记忆窗口（`M`）多数无害 | 只改统计口径，行为等同母策略 |

## 七、结论的修正史

这一节记录**我错了四次**，以及每次错在哪。

| 轮次 | 我宣布的冠军 | 错在哪 |
| :--- | :--- | :--- |
| 1（47 候选） | `R1-2` | 实验设计无选择压，份额全挤在 1/10 |
| 2（322 候选） | `D0+R1-1`（0.2639，夺冠 100%） | 组内假象：只面对 6 个弱对手；同场决赛后掉到 33% 夺冠 |
| 3（分层决赛） | `S0` / `R1-1` | 决赛 100% 是 R 家族，缺 `BS`/`S`/`F`/`T`/`W`/`AD` 默认槽与 `P`/`B`/`K`/`H`/`RC` 触发器 |
| 4（含末轮背刺） | **`BS3+R1-1`** | 跨层全搜索已确认（第九节）：平均份额第一，但最差 seed 被清零 |

**共同病根**：候选池按"模块类型"分层扫（`R` 扫得最细），却漏了**跨层组合**。
这类盲点无法靠推理发现，只能靠"与引擎自己的随机生成对照"暴露。

## 八、稳健的结论

| 结论 | 证据 |
| :--- | :--- |
| `SM`（永远背叛）必被清退 | 分层决赛 3–40% 存活；从不是赢家 |
| 纯随机生成 ≪ 手工构造 | 17 倍份额差距（C 组 vs D 组） |
| 末轮背叛是压倒性增益 | 受控实验 +129% ~ +212% 份额 |
| **多样性决定生态健康** | D 组适应度 2.90 / Shannon 2.69，远高于 A/B/C |
| `R` 家族是最强范式 | 对多样对手时 `P`/`B`/`K`/`H`/`RC` 全部 0% 存活 |
| **噪声模块（`C`）在报复生态中致命** | 三次独立运行 100% 灭绝 |
| 记忆窗口（`M`）多数无害 | 322 → 160 归并中大量别名 |
| 生态多样性 ≠ 个体最优 | 末轮背刺 100% 覆盖时适应度 -3.3% 而份额不变 |

## 九、跨层组合全搜索（已完成）

第八节最后一条盲区（候选池按模块类型分层扫、漏了跨层组合）已用一轮全搜索补上。

**设计**：`默认槽 {S,F,T,D,AD,W,BS} × 触发器 {R,P,B,K,H,RC} × 修正槽 {—,M,C,RPT}`
共 **423** 个候选；12 seed × 250 代，每组固定 7 席、填充 `S0` + `SM`。
产物：`reports/tournament_cross.json`。

### 9.1 结果

| 排名 | 候选 | 平均份额 | 终局份额 | 存活率 | 夺冠率 | 最差 seed |
| ---: | :--- | ---: | ---: | ---: | ---: | ---: |
| 1 | **`BS3+R1-1`** | **0.3443** | 0.3892 | 75% | 100% | **0.0000** |
| 2 | `F1-1+R2-2` | 0.2934 | 0.3208 | 92% | 100% | 0.0400 |
| 3 | `BS2+R1-3` | 0.2729 | 0.3175 | 92% | 75% | 0.0775 |
| 4 | `D0+R1-3` | 0.2300 | 0.2175 | 75% | 100% | 0.0607 |
| 5 | `T1-2+R2-2` | 0.2225 | 0.2292 | 83% | 50% | 0.0000 |

### 9.2 四个发现

1. **跨层组合里确实藏着此前的搜索够不到的最优解。** `F1-1+R2-2`（第 2 名，0.2934）
   是"默认槽 × 触发器"的交叉组合——早先的候选池只让默认槽与**修正槽**组合
   （见 `tools/tournament.py` 中 `cross_layer_pool()` 的说明），**结构上产生不出它**。
   盲区的存在被证实。

2. **`BS3+R1-1` 确认第一，但代价是脆弱。** 平均份额最高（0.3443）、
   12 个 seed 全部登顶，却在最差 seed 上被**清零**（`worst_share = 0`）。

3. **强度与稳定是一对取舍。** 唯一 100% 存活的批次冠军是 `BS2+R1-1`（0.1750）——
   末轮背叛 2 轮反而比 3 轮**更稳**。这与第五节 `BS2` 生态适应度 -0.061 的
   异常同向：`BS2` 可能是在用峰值换稳定。

4. **绝大多数组合是死路。** 423 个候选里 **227 个（54%）存活率 0%**，
   仅 14 个能 100% 存活。跨层搜索的价值不在"组合得多"，
   而在于**证明大多数组合互相抵消**。

### 9.3 落地建议

`BS3+R1-1` 最强、`BS2+R1-1` 最稳。若要在"邀请用户对战"的场景里选一个
默认 AI 对手，**取 `BS2+R1-1`**：稳定在场、不会突然消失，体验更可预期。

> **仍未解决**：第五节 `BS2` 生态适应度 -0.061 的异常。本轮只测相对份额
> （`mean_share`/`survival`），**不测绝对适应度**，故不能据此判定，仍需专门实验。
